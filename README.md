# موقع مكتبة كرم - تصميم محدث

واجهة عربية RTL مستوحاة من الصورة المرجعية، بألوان الأزرق والأحمر والأصفر، مع واجهة رئيسية وبطاقات الخدمات وطلب الطباعة وكتالوج المنتجات ولوحة الإدارة.

## التشغيل
- يتطلب Node.js 20 أو أحدث.
- نفّذ `npm install` ثم انسخ `.env.example` إلى `.env` وعدّل كلمة مرور المدير وSESSION_SECRET.
- نفّذ `npm start` وافتح `http://localhost:3000`.
- يدعم رفع ملفات PDF وWord والصور وExcel حتى 15MB، وحفظ الطلبات والمنتجات في SQLite.

## قبل النشر
يجب استخدام استضافة تدعم Node.js وتخزيناً دائماً لمجلدي `data` و`uploads`، وتعيين أسرار قوية في متغيرات البيئة وتفعيل HTTPS. هذه الحزمة لم تُنشر على الإنترنت بعد ولا يوجد لها رابط عام حالياً.
